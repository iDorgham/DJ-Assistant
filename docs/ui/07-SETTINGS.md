# 07 — Settings

**Version:** 1.0 · **Date:** 2026-10-19

Settings open as a **dedicated window or full modal page**: left category list + right content. Searchable.

Shortcut: `Ctrl/Cmd+,`

---

## 1. Categories

### General
- Language  
- Startup view (Library / Preparation / Auto Performance / last used)  
- Default density  
- Confirm before quit  
- Session restore on/off  

### Library
- Watched folders (add/remove)  
- Auto-analyze on add  
- Duplicate policy (hash / duration+BPM hint)  
- Allowed file types  

### Analysis
- BPM / key engine options (as exposed)  
- Key display: Camelot / classical / both  
- Harmonic match: Strict / Wide  
- Energy model notes  
- Re-analyze policy  

### Cues & Grid
- Default hot-cue count and colors  
- Snap defaults  
- Phrase detection sensitivity  
- Click cue starts playback on/off  

### Playback
- Output device  
- Buffer / latency preference  
- Auto-play on select  
- Follow playhead on/off  
- Scrub preview on/off  

### Export
- Default format (rekordbox XML / Serato crate / USB)  
- USB folder structure template  
- Filename template  
- Export preview always on/off  

### Skills & Automation
- Enable/disable each Skill  
- Confirm before bulk apply  
- Undo history size  

### Appearance
- Theme: Dark / Light / System  
- Accent color (optional)  
- Waveform color family  
- Density default  
- UI scale note (target compact ~85%)  

### Keyboard
- Searchable shortcut list  
- Rebind with conflict detection  
- Reset shortcuts  

### Privacy
- Local-only analysis statement  
- Optional cloud features opt-in (collab, etc.)  
- Crash report opt-in  

### Advanced
- Cache location  
- Log level  
- ONNX thread preference  
- Reset layout  
- Reset all settings (confirm)  

---

## 2. UX rules

- Search settings field at top  
- Apply immediately when safe; mark restart-required items  
- Short description per section  
- Danger actions require confirmation  
- Persist locally; optional settings export/import (P1)  

---

## 3. Acceptance

- All categories reachable and searchable  
- Theme and density apply without restart  
- Keyboard list accurate vs real shortcuts  
- Reset layout restores factory docks
