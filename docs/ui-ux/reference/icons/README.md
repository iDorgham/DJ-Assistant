# Candidate icon images

The five inspiration PNGs the user supplied for the **brand mark** — memory decision
[D-020 "The brand mark is The Stack"](../../../ai/memory/decisions.md) chose "Stack + Play"
from them; the shipped mark lives in [`assets/`](../../../../assets/README.md). They were
untracked in `docs/ui/` and are renamed here by what they show.

They are **not** a UI icon set: they mix filled and outline families. In-app icons
stay on one pack — Lucide outline — per [01-DESIGN-SYSTEM §8](../../01-DESIGN-SYSTEM.md)
(audit finding U-20, task TU.13).

| File | Shows |
|------|-------|
| `library-books-filled.png` | Three books, one leaning (library) |
| `library-stack-note-filled.png` | Stacked cards with a note (music library) |
| `music-library-outline.png` | Same idea, outline style |
| `playlist-play-stack-filled.png` | Stacked cards with a play glyph |
| `playlist-play-lines-filled.png` | Card with play glyph under two lines |
