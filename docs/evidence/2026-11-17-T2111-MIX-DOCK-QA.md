button in `MixSuggestionsDock.tsx`, wired in `App.tsx`). Completes the
Preview / Add to set / Replace triad on the Mix suggestions dock.

Environment: real Tauri desktop app (`dj-assistant-desktop.exe`, window 7144764)

## Findings

- **F-1 (UX, out of slice scope):** with both open, the TrackPanel paints over
  the Mix dock — the dock is `absolute right-0 z-20` inside the main workspace
  and the panel covers its region, so the dock looks broken until the panel is
  closed. Worth a follow-up (shift layout or auto-close).
- Selection is UI state only: Add/Replace never write the DB, which the
  cross-check confirms (row count and content stable through the session).
- Preview decode of the ONNX-less mp3 fell back to the synthetic symphonia
  error path (`audio-engine.ts:198`, unsupported audio codec) — pre-existing
  player behavior on this box, unrelated to the slice; the track still loads
  into the deck.
- Low-level caveat carried from unit tests: order-preserving replace and the
  append branches are covered by `mix-dock-actions.test.ts` (7 cases); the
  running-window QA verified the observable outcomes, not array identity.

## Verdict

T2.1.11 Replace action: **PASS** in the running window (steps 1–6). The
`04-TASKS.md` box stays unticked pending the human's tick on main.
