# Prompts

Reusable prompts for recurring AI-driven work on this repository. A prompt here
is a **template**: copy it, fill the bracketed parts, run it. Agent definitions
and routing live in [`docs/ai/`](../ai/AGENTS.md) and `.opencode/`, not here.

| Prompt | Use for |
|--------|---------|
| [ui-and-docs-audit.md](ui-and-docs-audit.md) | A UI/UX audit of the running app plus a docs/plans consistency check |

Rules: say what the prompt needs (running app, fixture DB), where output goes
(`docs/audits/`), and what it must not do (write to the live library, commit).
