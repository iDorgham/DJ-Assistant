## Overall Impression

The single biggest baseline opportunity — "make the app honest" — is largely paid down on the visible surface: fabricated numbers are gone or badged, dead nav is now labeled roadmap, destructive cues are undoable, and both themes scan clean at AA. The app now reads as a coherent, disclosure-forward DJ instrument over a documented skeleton. The biggest remaining opportunity is state discipline: the main table and genre filter still tell confident lies when loading or when the backend fails, which undercuts the honesty work everywhere else.

## What's Working

1. Domain-authentic player hardened rather than cosmetically patched: CDJ-correct CUE, visible hover/focus × with a keyboard-reachable Undo toast, arrow/Home/End seeking with `aria-valuetext` timecodes, wheel-zoom wired to its documented behavior, splitter as a real `role="separator"`.
2. Honest IA: nav narrowed to what works, four planned surfaces demoted to a read-only Roadmap strip, placeholders self-disclose "Planned view" and say what ships when — the primary journey no longer dead-ends at step 2.
3. Token-driven visual system that now survives its own audit: `--text-muted`/light `--cue`/light `--accent` AA errata documented in docs/ui/01 §3, 11px floor enforced, detector clean, contrast-verified in both themes.

## Priority Issues

- [P1] Inspector drawer is pointer-only: `<tr onClick>` (App.tsx:1674) with no tabindex, role, or key handler is the sole entry to similar tracks, tag gaps, store links, and Deezer match — keyboard and screen-reader users cannot reach a whole shipped panel at all, and there is no workaround. Fix: per-row "Inspect" affordance (or APG grid pattern with Enter/Space), move focus into the drawer on open, label it `role="complementary"`/dialog as appropriate. -> /impeccable harden
- [P2] Disclosure scope is narrower than the fabrication scope: phrase bands ("DROP 1", "BREAKDOWN") are deterministic duration percents and hot cues A–D are pre-placed at synthesized positions, but the badge copy covers only "waveform shape/peaks" — and the mini player (the default mode) renders neither the waveform badge nor the synth-audio pill at all, only a hover title on Play. Fix: broaden badge copy to structure/cues or suppress phrase labels (the baseline fix that was not applied); add a compact disclosure in mini mode. -> /impeccable clarify
- [P2] Typed error states incomplete (baseline P2 only half-paid): first-load failure renders a confident empty library, genre-fetch failure renders "No genre tags in the library yet", Tag Health load failure says "Could not load tag health." with no retry, and enrichment/chart failures still dump raw `${err}`. Fix: loading|error|empty per section, sanitize copy, Retry everywhere. -> /impeccable clarify
- [P2] False keyboard affordances persist + a scoping side effect (baseline P2 open): zoom buttons titled "Zoom out (−)" / "Zoom in (+)" have no key handlers anywhere; the shortcut legend exists only before a track is selected; and the new scoping excludes ALL buttons, so C and 1–8 silently die whenever any button holds focus (the common state after any click) — only Space needed that exclusion. Fix: wire or retitle zoom keys, keep a compact legend visible with a track loaded, scope by key rather than by element tag. -> /impeccable harden
- [P2] Full-player bottom row still ~30 always-visible controls with no progressive disclosure (baseline P2 open): beat-jump (7) + snap/nudge/BPM/reset (6) + transport (5) + 8 pads + 8 clear × + zoom cluster (5) compete in one row. Fix: collapse grid tools behind a popover/disclosure, keep transport + pads + jump primary. -> /impeccable layout

## Persona Red Flags

- **Alex (power user)**: keyboard seek, sortable server-side columns, and beat-jump are real now — but there is still no command palette, no bulk/multi-select (cues and rows), and C/1–8 shortcuts stop working the moment any button has focus. Searching a large library filters only the loaded 200-row window, so matches beyond it are silently missed until Load more. Abandon risk moderate (down from high).
- **Sam (a11y)**: contrast, tiny text, slider keyboard support, and modal focus trap are all fixed and verified — then hit a wall: the inspector drawer is unreachable by keyboard entirely. The header volume slider is tab-reachable but width-0/opacity-0 until pointer hover (invisible focus target) and displays 0 while muted. Cue toolbar = 16 individual tab stops (8 pads + 8 ×), no roving tabindex. View state announced two different ways (aria-pressed vs aria-current).
- **Riley (stress tester)**: backend down on first load → table says "No tracks in library" while a 11px status line disagrees; genre fetch failure blames the user's tags; filter popover (z-40) can float above an open modal (z-30); Ctrl/Cmd+1–3 while a dialog is open unmounts it abruptly (focus-return targets a detached node); index.html meta still promises "arrange sets … and exports for rekordbox, Serato, or CDJ" in present tense.

## Minor Observations

- Header volume slider remains hover-only with `value={headerMuted ? 0 : headerVolume}` — the thumb snaps to 0 while muted and dragging muted changes the stored volume invisibly; no `aria-valuetext` here (TransportSection has it).
- `openTagHealth`/`openCharts` do not close an open filter popover; Escape collapses everything at once rather than layering.
- ModalShell: no backdrop dismiss, no body scroll lock; the trap only guards first/last focusables, so focus landing on the backdrop (click → body) can Tab into the background before re-entering.
- Overview map interaction is mouse-only (click/drag); acceptable only because zoom buttons + arrow seek provide an equivalent path.
- `user-select: none` on body means file paths, ISRCs, and comments can't be selected without the provided Copy buttons.
- Canvas hex literals remain hard-coded per theme (`isDarkTheme` ternaries) instead of reading CSS custom properties — documented Bucket 2 debt, values verified AA.
- Search is client-side over the fetched page only; the "No tracks match" empty state doesn't mention that rows beyond `visibleLimit` were never searched.
